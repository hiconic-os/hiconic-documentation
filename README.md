# Hiconic

> Status: skeleton. Each section states the question it must answer. Answers are written in Phase 3, from code.

Hiconic is an open source application platform. It has three layers, and each layer is useful on its own.

| Layer | Group | What it gives you |
|---|---|---|
| [Wire](wire/wire.md) | `com.braintribe.wire` | Dependency injection in which the wiring is ordinary Java code |
| [Generic Model](generic-model/generic-model.md) | `com.braintribe.gm` | A type system for entities, and the APIs built on it |
| [Reflex](reflex/reflex.md) | `hiconic.platform.reflex` | A modular application platform |
